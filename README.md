# Melica Resort Phu Quoc

Premium tropical resort landing page built with Next.js, TypeScript, Tailwind CSS v4, Framer Motion and Lucide React.

## Included

- Editorial luxury resort visual direction
- Responsive desktop / tablet / mobile layout
- Sticky navigation + mobile menu
- Floating section navigation on desktop
- Hero, resort story, pool, rooms, dining, location and booking CTA
- Booking.com availability CTA
- Smooth anchor navigation and motion interactions

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Notes

Property facts and amenity copy are based on the public Booking.com listing available in 2026. Rates are intentionally not hard-coded because live prices vary by dates, room and offers.
